# Numerical verification and applicability

## Original behavior and focused SI-constant correction

Before changing calculations, an independent test using exact SI constants
`h = 6.62607015e-34 J s`, `c = 299792458 m s^-1` demonstrated that
`units/calibration.rs::HC = 1.986445857148968e-25 J m` differed from
`h*c = 1.9864458571489286e-25 J m` by **+1.976377783781592e-14 relative**.
The original implementation failed the `3e-15` relative SI-oracle tolerance.
The test's expectation derives from SI definitions and explicit cm²/ns scaling,
not from NSB output. No tolerance was relaxed.

Impact review before modification: this private HC constant has one caller,
`s10_for_spectral_photon_radiance`. Its output is the B/V monochromatic S10
**diagnostic** from a spectral photon radiance. Correcting HC decreases those
S10 values by about 2e-14 relative and changes corresponding magnitudes by
about +2.15e-14 mag where those diagnostics are used. Integrated photon radiances,
model spectra, band integrals, atmosphere, solver iterations and physical models
are unchanged. This is negligible relative to physical model uncertainty, but
is recorded as a numerical correctness change. Historical observational results
are left intact; no accuracy ranking or recalibration follows from it.

The correction evaluates `6.62607015e-34 * 299792458.0` as a constant. The focused
16-case regression tests zero and positive spectral photon densities at
300, 445, 551 and 650 nm. The 3e-15 relative tolerance allows arithmetic rounding
in the typed unit conversion and the independent SI expression, while detecting
the original ~2e-14 constant error. Zero must remain exactly zero.

## Receipt contracts

`numerical-verification.json` is generated by `publication_probe numerical`.
It records every actual/reference value, physical units, input, tolerance and
absolute/relative error; a failed row causes a nonzero exit code.

| Family | Oracle and tested operation | Domain / tolerance | Interpretation |
| --- | --- | --- | --- |
| clipped_linear | Constant/linear synthetic density; exact trapezoid integral; Optica trapz_range, the exact delegated NSB band kernel | Irregular 300–650 nm nodes, full and clipped ranges; absolute 1e-10 radiance | Independent quadrature algebra, not physical spectrum accuracy |
| quadratic_convergence | y=((lambda-300)/350)^2, integral 350/3; trapezoid error 350/(6 n²) | n=8,16,32,64; error-law residual <=1e-10 | Second-order convergence of kernel; no claim of adjustable component-grid convergence |
| radiance_units | 1 ph cm^-2 ns^-1 sr^-1 = 1e13 ph m^-2 s^-1 sr^-1 | Typed qtty conversion; abs 0.01 in SI (~1e-15 relative) | Dimensional scale check |
| beer_lambert_composition | exp(-tau/cos(z)); NSB DirectTransmission with PlaneParallel airmass | 360,500,650 nm; z=0,30,60,80 degrees; abs 2e-14 | Independent algebra given API-computed vertical tau; does not independently verify empirical optical-depth models |

The existing workspace suite provides broader limiting, domain, coordinate,
source-origin, unit, scattering-reference and convergence coverage (see README).
Its aggregate receipts do not invent observed error maxima for tests that only
assert tolerances. Those tests retain their own reference provenance and domains.
The photon-to-S10 test is separately identified in the workspace log; no claimed
maximum error is fabricated for it.

Coordinate absolute accuracy against an independent ephemeris: **NOT APPLICABLE
to the new receipt probe**. Frame conversion is checked by shared input semantics
and existing round-trip tests; that is consistency evidence.

No quadrature error here is a physical uncertainty estimate. No observational
measurements, protected LVM products, fits or recalibrations are involved.
