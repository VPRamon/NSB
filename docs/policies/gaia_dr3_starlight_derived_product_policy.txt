Scope

This policy applies only to the NSB Gaia DR3 XP-derived starlight runtime product generated by the maintainer release pipeline. The approved redistributable runtime product is the derived HEALPix starlight map CSV and its runtime TOML manifest after successful scientific validation, checksum pinning, and manifest registration.

This policy does not approve committing raw Gaia XP spectra, raw Gaia source-row dumps, Gaia DataLink response bodies, intermediate normalized XP chunks, or full Gaia release-input extracts to the NSB repository. Those files are release-build working data and must remain outside the repository unless a separate maintainer decision explicitly changes that rule.

Reviewed source basis

The Gaia DR3 documentation release 1.3 is published by the European Space Agency and the Gaia Data Processing and Analysis Consortium. It states that Gaia DR3 contains astrometry, broad-band photometry, mean BP/RP and RVS spectra for large source subsets, and other Gaia DR3 data products. It also states that Gaia DR3 data can be retrieved from the Gaia ESA Archive and that large data products, including spectra, are accessible through a DataLink service.

The same Gaia DR3 credit and citation instructions state that Gaia data are open and free to use, provided credit is given to ESA/Gaia/DPAC. NSB will preserve that credit in documentation, release notes, and runtime provenance for the derived starlight product.

Required acknowledgement

Every release note, documentation page, or paper describing a production Gaia-derived NSB starlight map must include the following acknowledgement or an equivalent acknowledgement required by the Gaia DR3 documentation:

This work has made use of data from the European Space Agency mission Gaia, processed by the Gaia Data Processing and Analysis Consortium. Funding for the DPAC has been provided by national institutions, in particular the institutions participating in the Gaia Multilateral Agreement.

Required citations

Scientific documentation for a production Gaia-derived NSB starlight map must cite the Gaia mission paper and the Gaia DR3 release paper. It should also cite Gaia DR3 validation and BP/RP processing papers when discussing scientific validation, photometry, XP spectra, or limitations.

Approved source selection

The production release-input extraction is approved only for the documented Gaia DR3 XP source selection used by NSB:

- source catalogue: Gaia
- source catalogue release: DR3
- archive table: gaiadr3.gaia_source
- spectra source: Gaia DR3 XP sampled spectra retrieved through Gaia DataLink
- source filter: duplicated_source = false
- XP availability filter: has_xp_sampled = true
- required astrometric fields: source_id, ra, dec, ref_epoch
- required photometric source limit: configured phot_g_mean_mag limit, normally G <= 20
- approved passband for the derived runtime product: 330-650 nm passband-integrated photon radiance

Approved repository artifacts after validation

Only these derived runtime artifacts are approved for possible repository inclusion after successful production validation and size review:

crates/nsb/data/starlight_gaia_dr3_xp_330_650nm_nside128_v1.release.csv
crates/nsb/data/starlight_gaia_dr3_xp_330_650nm_nside128_v1.manifest.toml

The release CSV and runtime manifest must be generated by repository Rust tools, checksum pinned, self-loaded by pack_starlight_asset --production through the runtime ValidatedStarlightMap admission path, and registered in crates/nsb/data/manifest.toml as runtime_embedded production assets.

Files excluded from repository inclusion

The following files must not be committed as part of this policy:

- raw Gaia XP spectra
- raw Gaia source-row dumps
- Gaia DataLink response bodies
- intermediate normalized XP chunk files
- full Gaia release-input extracts
- temporary curl output
- local cache files from Gaia TAP or DataLink retrieval

Production gates

The final production artifact may be bundled only when all of the following are true:

1. Gaia production extraction diagnostics show zero rejected selected sources, zero XP chunk failures, and at least one accepted XP source.
2. The canonical Gaia source CSV checksum is recorded.
3. The generated HEALPix map checksum is recorded.
4. The runtime manifest checksum is recorded.
5. Integrated photon-radiance flux conservation passes.
6. Finite and nonnegative integrated radiance validation passes.
7. Integrated plane/pole validation passes.
8. Integrated longitude seam and wrap validation passes.
9. Structured independent regional comparison passes using the reviewed validation reference file.
10. The production packer self-loads the emitted CSV and TOML through ValidatedStarlightMap.
11. The release checklist records the final artifact paths, checksums, commands, and validation report.

Decision

NSB may generate and redistribute the derived Gaia DR3 XP starlight runtime map CSV and TOML manifest after the production validation gates pass. NSB must credit ESA/Gaia/DPAC and must cite the Gaia mission and Gaia DR3 release papers in scientific documentation. NSB must not commit raw Gaia XP spectra, raw Gaia source-row dumps, Gaia DataLink responses, intermediate XP chunks, or full release-input extracts under this policy.
