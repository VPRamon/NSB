# Starlight uncertainty contract

This document is the term-by-term glossary for every uncertainty quantity
that flows through the Starlight pipeline, from per-source Gaia inputs to the
published canonical map and merge report. It is generated by reading the
current implementation (`accumulator.rs`, `uv.rs`, `photometric.rs`,
`selection.rs`, `worker.rs`, `product.rs`, `xp/mod.rs`) and is expected to be
kept in lockstep with it — if a formula below stops matching the code, the
code (or this document) has a bug.

Companion material:

- [`docs/nsb_components/starlight/map-validation.md`](map-validation.md) — structural
  and cardinality validation of the canonical map and report.
- `crates/nsb-data-tools/src/starlight/worker/uncertainty_fixtures.rs` and
  `crates/nsb-data-tools/src/starlight/map/product.rs`
  (`two_pixels_sharing_a_global_systematic_add_linearly_when_merged`) — the
  hand-checkable analytical fixtures that exercise every rule documented here.

## Correlation-scope vocabulary

[`crate::starlight::uncertainty::CorrelationScope`] (module `starlight::uncertainty`)
names the spatial/population extent over which an uncertainty term's error is
*shared*. It is a diagnostic vocabulary layered on top of the two correlation
regimes the code actually implements today
([`crate::starlight::uv::SystematicCorrelation`]); it does not change any
combination rule.

| `CorrelationScope` | Meaning | Produced today by |
| --- | --- | --- |
| `IndependentSource` | Drawn independently per admitted source; combines in quadrature both within a pixel and across pixels. | `SystematicCorrelation::IndependentBetweenSources` (statistical uncertainty everywhere; systematic uncertainty on the measured-only 336-650 nm path and on any UV artifact that declares independent systematics). |
| `PixelCorrelated` | Shared by every source in one HEALPix pixel, independent across pixels. | Nothing yet — reserved for a future per-pixel systematic (e.g. a per-pixel dust or background calibration term). |
| `RegionCorrelated` | Shared by every source within a declared sky region (e.g. one selection-function calibration tile), independent across regions. | Nothing yet — reserved for a future region-conditioned systematic. |
| `GlobalCorrelated` | Shared by every admitted source in the whole candidate; combines linearly (never in quadrature), both within a pixel and when pixels are merged into a global total. | `SystematicCorrelation::FullyCorrelatedBetweenSources` (the UV 300-336 nm correction systematic, when the pinned artifact declares this regime). |

`SpectralCoverageReport.systematic_correlation_scope` carries this mapping
into the merge report as an additive field alongside the pre-existing
`systematic_correlation` field.

## 2. Photometric fallback inference (`photometric.rs`)

Used only when a source has no admissible XP continuous spectrum; routes to
one of three ordered linear branches (`photometric_g_bp_rp` →
`photometric_partial` → `photometric_g_only`).

| Symbol / field | Meaning | Unit | Var vs stddev | Domain | Spatial correlation | Source correlation | Transform | Accumulation rule |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| `score`, `flux_336_650_ph_m2_s` | Linear (or log-linear, per `PhotometricResponse`) point estimate of measured-band flux from `[1, predictors...]`. | ph m⁻² s⁻¹ | value | `> 0`, finite (branch rejected otherwise) | n/a | n/a | `AbsolutePhotonFlux`: score is the flux directly. `NaturalLogPhotonFlux`: `flux = exp(score)`. | One value per source; becomes `flux` input to `worker::admit_weighted_source`. |
| `variance` (design-weighted covariance diagonal) | `sum_i covariance[i][i] * design[i]^2`: parameter covariance propagated through the design vector (no cross terms — only diagonal is used). | (ph m⁻² s⁻¹)² for `AbsolutePhotonFlux`; dimensionless (score units)² for `NaturalLogPhotonFlux` | variance | `>= 0`, finite | none (per source) | `IndependentSource` | Diagonal-only quadratic form | Consumed immediately below; not itself accumulated. |
| `statistical_uncertainty_336_650_ph_m2_s` | Statistical floor combined with propagated parameter uncertainty. | ph m⁻² s⁻¹ | stddev | `>= 0`, finite | none | `IndependentSource` | `AbsolutePhotonFlux`: `hypot(sqrt(variance), statistical_floor)`. `NaturalLogPhotonFlux`: `hypot(flux * sqrt(variance), statistical_floor)` — this is the same "flux × sigma_ln" relative-uncertainty transform used by the UV log-ratio response (§4). | Feeds `statistical` into `worker::admit_weighted_source`. |
| `systematic_uncertainty_336_650_ph_m2_s` | Floor-plus-fractional systematic model. | ph m⁻² s⁻¹ | stddev | `>= 0`, finite | none | `IndependentSource` (folded into `photometric_systematic` before admission; see §5 limitation) | `hypot(systematic_floor, flux * systematic_fraction)`, multiplied by `out_of_domain_policy.factor` when clamped | Feeds `photometric_systematic` into `worker::admit_weighted_source`. |

## 3. Selection-function completeness weighting (`selection.rs`)

Converts an inverse-completeness weight and a faint-tail systematic
contribution from a pinned, sky/magnitude/colour-conditioned artifact.

| Symbol / field | Meaning | Unit | Var vs stddev | Domain | Spatial correlation | Source correlation | Transform | Accumulation rule |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| `completeness` | Estimated fraction of true sources recovered in a (healpix, G, BP-RP) cell. | dimensionless | n/a | `(0, 1]` | Region-conditioned (per healpix/mag/colour cell); currently reported diagnostically as `IndependentSource` per admitted source, not as `RegionCorrelated` — see limitation below. | derived, not itself a per-source draw | Table lookup or `m10_to_completeness` logistic model | Not summed; consumed per source. |
| `weight` (`w`) | Inverse-completeness weight, `1/completeness` clamped to `[1, weight_cap]`. | dimensionless | n/a | `[1, weight_cap]` | same as `completeness` | n/a | `(1/completeness).min(weight_cap).max(1.0)` | Multiplies `flux` and `statistical` linearly (see §5); not itself accumulated. |
| `systematic_uncertainty_fraction` | Faint-tail systematic fraction, nonzero only past `faint_tail.magnitude_limit_g`. | dimensionless (a fraction of weighted flux) | n/a | `[0, 1]` | Shared by every source past the faint-tail magnitude cut — conceptually closer to `RegionCorrelated`/`GlobalCorrelated` than `IndependentSource`, but the code files it as `IndependentSource` today (folded via `hypot`, see §5 limitation). | see above | Constant lookup `faint_tail.systematic_fraction` | Feeds `selection_systematic_fraction` into `worker::admit_weighted_source`. |

**Documented limitation**: the selection-function completeness weight and its
faint-tail systematic fraction are genuinely *shared* across every source in
the same (healpix, magnitude, colour) cell or past the same faint-tail
magnitude cut — i.e. they are not really `IndependentSource` in origin. The
current accumulator has no `PixelCorrelated`/`RegionCorrelated` bucket, so
`worker::admit_weighted_source` files the resulting systematic term as
whatever the destination shard's `SystematicCorrelation` is (independent for
the measured-only 336-650 nm path). This is a known simplification, not a
bug; a future change that adds `PixelCorrelated`/`RegionCorrelated`
accumulator buckets should re-home this term.

## 4. UV correction (300-336 nm) (`uv.rs`)

Optional 300-336 nm correction applied only for the `Combined300To650`
product band, from a pinned, holdout-validated linear artifact.

| Symbol / field | Meaning | Unit | Var vs stddev | Domain | Spatial correlation | Source correlation | Transform | Accumulation rule |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| `score`, `flux_300_336_ph_m2_s` | Linear (or log-ratio) point estimate of the UV-band flux from `[1, predictors...]`. | ph m⁻² s⁻¹ | value | `AbsoluteUvPhotonFlux`: `>= 0` (rejected otherwise). `NaturalLogUvToMeasuredFluxRatio`: `flux = measured_336_650 * exp(score)`, must be finite. | n/a | n/a | `AbsoluteUvPhotonFlux`: score is the flux. `NaturalLogUvToMeasuredFluxRatio`: `flux = measured_flux * exp(score)` (log-ratio to the measured band). | One value per source. |
| `score_variance` | `transformed^T . covariance . transformed`: full (non-diagonal) quadratic form over the model's parameter covariance. | (score units)² | variance | `>= 0`, finite | none (per source) | `IndependentSource` | Full quadratic form (unlike the photometric diagonal-only case) | Consumed immediately below. |
| `statistical_uncertainty_300_336_ph_m2_s` | Statistical floor combined with propagated model uncertainty. | ph m⁻² s⁻¹ | stddev | `>= 0`, finite | none | `IndependentSource` | `AbsoluteUvPhotonFlux`: `hypot(sqrt(score_variance), statistical_floor)`. `NaturalLogUvToMeasuredFluxRatio`: `conditional_statistical = hypot(flux * sqrt(score_variance), statistical_floor)` — **this is the `flux * sigma_ln` relative/log-uncertainty transform** (first-order propagation of `d(exp(ln_flux))/d(ln_flux) = flux`); then combined with the measured band's own uncertainty and their correlation (`rho`) into `sqrt(conditional_statistical^2 + measured_contribution^2 + 2*rho*conditional_statistical*measured_contribution)`. | Feeds into `combine_with_measured` below. |
| `rho` (`measured_conditional_residual_statistical_correlation`) | Correlation between the measured XP statistical error and the conditional UV-model residual (excludes the log-ratio's structural shared-flux dependence, which is handled separately via `measured_correction_statistical_covariance_ph2_m4_s2`). | dimensionless | n/a | `[-1, 1]` | n/a | n/a (a fixed artifact constant, not per-source) | Constant from the pinned artifact | Used only inside `combine_with_measured`'s covariance term; never accumulated on its own. |
| `systematic_uncertainty_300_336_ph_m2_s` | Floor-plus-fractional systematic model on the UV-band flux. | ph m⁻² s⁻¹ | stddev | `>= 0`, finite | Whatever the pinned artifact declares via `uncertainty_model.systematic_correlation` — see `CorrelationScope` above. | `IndependentSource` **or** `GlobalCorrelated`, per artifact | `hypot(systematic_floor, flux * systematic_fraction)`, multiplied by `out_of_domain_policy.factor` when clamped | `IndependentBetweenSources`: added in quadrature into `PixelAccumulator.systematic_variance` (per pixel). `FullyCorrelatedBetweenSources`: added linearly into `PixelAccumulator.systematic_correlated_uncertainty` (per pixel), and linearly again across pixels when merged into a global total (§6, §7). |
| `combined.statistical_uncertainty_300_650_ph_m2_s` | Statistical uncertainty of the combined 300-650 nm flux. | ph m⁻² s⁻¹ | stddev | `>= 0`, finite | none | `IndependentSource` | `sqrt(sigma_measured^2 + sigma_uv^2 + 2*covariance)`, where `covariance` is either the log-ratio's exact structural covariance or `rho * sigma_measured * sigma_uv` | Feeds `statistical` into `PartitionShard::admit_corrected`. |
| `combined.systematic_uncertainty_300_650_ph_m2_s` | Systematic uncertainty of the combined 300-650 nm flux; UV systematic only (photometric/selection systematic is hypot-folded in separately by `worker::admit_weighted_source`, see §5). | ph m⁻² s⁻¹ | stddev | `>= 0`, finite | matches `systematic_uncertainty_300_336_ph_m2_s` above | matches above | `= systematic_uncertainty_300_336_ph_m2_s` (the combine step does not add a separate measured-band systematic; the 336-650 nm systematic only exists in the measured-only, non-UV-corrected candidate) | See §5-§6. |

## 5. Admission combination (`worker.rs`)

`admit_weighted_source` is where completeness weighting, photometric/XP
statistical uncertainty, and (optionally) the UV correction are combined into
the exact `(flux, statistical, systematic, correlation)` tuple handed to the
pixel accumulator.

| Symbol / field | Meaning | Unit | Var vs stddev | Domain | Spatial correlation | Source correlation | Transform | Accumulation rule |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| `weighted_flux` | Completeness-corrected flux. | ph m⁻² s⁻¹ | value | `> 0` | inherits from `w` | inherits from `w` | `w * flux` | Input to accumulation. |
| `weighted_statistical` | Completeness-corrected statistical uncertainty. | ph m⁻² s⁻¹ | stddev | `>= 0` | inherits from `w` | inherits from `w` | `w * statistical` | Added in quadrature per pixel (§6). |
| `systematic` (measured-only path) | Combined photometric-model and selection-driven systematic. | ph m⁻² s⁻¹ | stddev | `>= 0` | `IndependentSource` (as filed; see §3 limitation) | `IndependentSource` | `hypot(photometric_systematic, selection_systematic_fraction * weighted_flux)` | Added in quadrature per pixel via `PartitionShard::admit` (always tags `IndependentBetweenSources`). |
| `combined.systematic_uncertainty_300_650_ph_m2_s` (UV-corrected path, post-fold) | UV-artifact systematic folded with the same measured-band photometric/selection systematic. | ph m⁻² s⁻¹ | stddev | `>= 0` | Inherits **the UV artifact's** declared `SystematicCorrelation`/`CorrelationScope`, even for the photometric/selection component — see limitation below. | see above | `hypot(uv_combined_systematic, photometric_systematic.hypot(selection_systematic_fraction * weighted_flux))` | Filed under whichever bucket (`systematic_variance` or `systematic_correlated_uncertainty`) the UV artifact's metadata declares, via `PartitionShard::admit_corrected`. |

**Documented limitation (fixture 7)**: on the `Combined300To650` path, one
pixel can genuinely admit sources whose systematic terms have two different
correlation-scope *origins* — a per-source photometric/selection systematic
(conceptually `IndependentSource`) and the UV artifact's declared systematic
(often `GlobalCorrelated`). `admit_weighted_source` folds these into one
number with `hypot` *before* admission, and the folded value is then filed
entirely under the UV artifact's declared bucket. This means a
`GlobalCorrelated` UV artifact currently causes the photometric/selection
component to be treated as if it, too, were globally correlated once folded
in. This is exercised directly by
`pixel_admits_combine_uv_and_photometric_systematics_before_tagging_correlation`
in `uncertainty_fixtures.rs` and is a known simplification pending a richer
per-term (rather than per-pixel) correlation model.

## 6. Pixel accumulation (`accumulator.rs`)

[`PixelAccumulator`] holds one HEALPix pixel's exact running sums
([`StableSum`], an exact binary64 superaccumulator: merging is associative
and commutative, and rounding happens only when a value is read).

| Field | Meaning | Unit | Var vs stddev | Accumulation rule (per admitted source) | Read-out transform |
| --- | --- | --- | --- | --- | --- |
| `flux_ph_m2_s` | Selected product-band (336-650 or 300-650 nm, per `product_band`) flux total. | ph m⁻² s⁻¹ | value | Exact sum of `selected_flux` | direct value |
| `statistical_variance` | Selected-band statistical variance total. | (ph m⁻² s⁻¹)² | variance | Exact sum of `selected_statistical^2` (**always** quadrature — `SystematicCorrelation` only ever governs the *systematic* channel) | `sqrt(...)` → statistical stddev |
| `systematic_variance` | Independent selected-band systematic variance total. | (ph m⁻² s⁻¹)² | variance | Exact sum of `selected_systematic^2`, only for sources tagged `IndependentBetweenSources` | `sqrt(...)` |
| `systematic_correlated_uncertainty` | Fully correlated selected-band systematic stddev total. | ph m⁻² s⁻¹ | stddev (summed directly, not as variance) | Exact sum of `selected_systematic`, only for sources tagged `FullyCorrelatedBetweenSources` | direct value |
| `selected_systematic_uncertainty()` | Pixel's total systematic uncertainty, combining both channels above. | ph m⁻² s⁻¹ | stddev | n/a (derived) | `sqrt(systematic_variance).hypot(systematic_correlated_uncertainty)` — the independent-quadrature total and the linear-sum total are themselves combined in quadrature with each other, since they represent two structurally different, uncorrelated-with-each-other error sources |
| `flux_300_336_ph_m2_s`, `flux_336_650_ph_m2_s`, `flux_300_650_ph_m2_s` and their `statistical_variance_*` counterparts | Same rules as above, tracked separately per sub-band for `band_diagnostics` regardless of which band is "selected" for the map. | ph m⁻² s⁻¹ / (ph m⁻² s⁻¹)² | value / variance | Exact sum, quadrature for statistical | `sqrt(...)` for variances |
| `systematic_variance_300_336_independent`, `systematic_uncertainty_300_336_correlated` | 300-336 nm-only systematic channels, same split as the selected-band systematic. | (ph m⁻² s⁻¹)² / ph m⁻² s⁻¹ | variance / stddev | Same split rule as `systematic_variance`/`systematic_correlated_uncertainty`, restricted to the 300-336 nm sub-band | `sqrt(independent).hypot(correlated)` in `band_diagnostics` |

`PixelAccumulator::merge` (used to combine per-worker shards for the *same*
pixel) adds every field above directly — including
`systematic_correlated_uncertainty`, confirming that fully-correlated terms
add **linearly**, never in quadrature, at every accumulation boundary from
individual sources up through worker-shard merges.

## 7. Merge report and global diagnostics (`map/product.rs`)

Values published once per candidate, over every occupied pixel.

| Field | Meaning | Unit | Accumulation rule |
| --- | --- | --- | --- |
| `BandDiagnosticsReport.systematic_uncertainty_300_336_ph_m2_s` / `..._300_650_ph_m2_s` | Global systematic uncertainty for the 300-336 nm and combined 300-650 nm sub-bands. | ph m⁻² s⁻¹ | `sqrt(sum_over_pixels(systematic_variance_300_336_independent)).hypot(sum_over_pixels(systematic_uncertainty_300_336_correlated))` — independent variance sums **across pixels** (quadrature), correlated uncertainty sums **across pixels** (linear), the two pixel-summed totals are then combined with `hypot`. ### Scale-plausibility gate

`scientific_gates` adds `uncertainty-scale-plausible`, which **fails**
(fail-loud, not an arbitrary scientific limit) when any of:

- `global_relative_total_uncertainty` is non-finite or negative;
- the median (`p50`) pixel relative total uncertainty exceeds `1.0` — i.e.
  more than half of occupied pixels would have an uncertainty budget larger
  than their own flux;
- more than `1%` of occupied pixels (`fraction_pixels_relative_uncertainty_gt_1`)
  have relative total uncertainty `> 1.0`;
- any occupied pixel (`fraction_pixels_relative_uncertainty_gt_10 > 0`) has
  relative total uncertainty `> 10.0`.

These thresholds are deliberately generous — noisy sky regions can
legitimately have relative uncertainty somewhat above `1` — but a
well-formed photon-flux uncertainty budget cannot plausibly exceed the
signal by an order of magnitude for even a single pixel, or exceed it at all
for a typical (`p50`) pixel. Either condition indicates a broken uncertainty
computation (unit error, runaway systematic term, mis-scaled artifact
coefficient, etc.), not legitimately noisy sky.

## Core combination formulas (summary)

These three rules recur at every accumulation boundary in the pipeline
(within one source's uncertainty budget, across sources in one pixel, and
across pixels in the global report):

```text
sigma_independent        = sqrt(sum(sigma_i^2))     # quadrature, uncorrelated terms
sigma_fully_correlated   = sum(sigma_i)             # linear, fully correlated terms
sigma_total              = hypot(sigma_statistical, sigma_systematic)
```

The published canonical map's `total_uncertainty_ph_m2_s` column is exactly
`hypot(statistical_uncertainty_ph_m2_s, systematic_uncertainty_ph_m2_s)`,
where `systematic_uncertainty_ph_m2_s` is itself
`hypot(sqrt(systematic_variance), systematic_correlated_uncertainty)` per §6.

## UV log-ratio floor contract

Log-ratio UV artifacts (`NaturalLogUvToMeasuredFluxRatio`) must encode
residual and systematic floors as dimensionless
`statistical_floor_log_ratio` / `systematic_floor_log_ratio`, converted to flux
units by the local Jacobian `F_UV`. Absolute CALSPEC holdout RMSE values must
not be copied into `statistical_floor_ph_m2_s` or `systematic_floor_ph_m2_s`.
The current production artifact is `calspec-linear-log-ratio-v2` (SHA-256
`5918a7960bf7b0eec5abee77987d66ef106940cc590434fc2805c82d7d602367`).
Candidates that violate this contract fail the `uncertainty-scale-plausible`
gate.
