# NSB data tools

> Generated from `crates/nsb-data-tools/tool-registry.toml`; do not edit manually.

`nsb-data` is the only supported data-product executable. Use `nsb-data --help` and a group-level `--help` to discover actions. Production actions fail closed on missing provenance, incomplete validation, checksum mismatch, schema errors, and unreconciled counts.

## Maintenance policy

New actions must be durable reusable capabilities, own no duplicate scientific or persistence logic, and be registered before implementation is exposed. Remove an obsolete action and its code, tests, registry entry, and documentation in the same change; do not retain wrappers, aliases, pilot commands, phase-named modules, or ad-hoc scripts.
