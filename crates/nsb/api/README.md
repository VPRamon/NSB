# `nsb` public API snapshot

`public-api.txt` is the machine-readable first-release inventory of crate `nsb`,
generated by `cargo-public-api` (`-sss`). Do not edit it by hand.

Regenerate and check with `cargo run --locked -p nsb-public-api-gate -- [--write]`.
Policy: [`docs/developer-guide/public-api.md`](../../../docs/developer-guide/public-api.md).
